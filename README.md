# Прокачка

Трекер хобби, где прогресс привязан не к очкам и часам, а к самому делу. Два трека, переключаются вкладками сверху:

- 🎹 **Пианино** — какие такты и какой рукой ты уже прошёл;
- 📖 **Чтение** — до какой страницы дочитал книгу.

У каждого — свой прогресс в процентах, свой календарь, своя серия дней и свои достижения.

Открыто на **https://buzulutskiy.github.io/prokachka/** · статический PWA без бэкенда: `index.html` + `app.js`. Данные — локально (localStorage), между устройствами синхронизируются через секретный **GitHub Gist**.

## 📖 Чтение

Зашита книга **Норштейн, «Снег на траве», том 1** (361 страница, прогресс стартует со 183-й — прочитанного до приложения). Название и объём правятся кнопкой «изменить».

- Отмечаешь, **до какой страницы дочитал**: степпер и быстрые кнопки +5 / +10 / +20 / +50. Показывает текущую главу и сколько страниц осталось.
- Общий прогресс-бар, процент прочитанного, «страниц за неделю», серия вечеров подряд.
- **24 достижения в норштейновском духе** и по большей части закрытые: 🌫️ «Вошёл в туман» (25%), 🦔 «Ёжик вышел из тумана» (глава дочитана), 🫖 «Медвежонок ждёт с самоваром» (10 вечеров), 🍎 «Вечное яблоко» (75%), 🌟 «Звёзды над колодцем» (90%), 🐺 «Волчок унёс книжку» (дочитал!). Секретные находишь сам: 🦉 «Филин следит» — читал в выходной, 🐴 «А лошадка-то в тумане» — вернулся на страницы назад, 🧣 «Как „Шинель“» — вернулся после долгого перерыва.

## 🎹 Пианино

Сейчас разбирается **Бах — Прелюдия es-moll, BWV 853** (40 тактов; название и число тактов правятся кнопкой «изменить»).

- **Карточка композиции** — общий процент разбора и две карты тактов: 𝄞 правая рука (скрипичный ключ) и 𝄢 левая (басовый). Каждый такт — клетка: тёмная (не трогал) → полупрозрачная (разобрал) → яркая (закрепил, 3+ прохода). Проценты по каждой руке отдельно.
- **Отметить занятие** — выбираешь руку (правая / левая / обе), диапазон «с такта — по такт» и жмёшь «Позанимался». Занимался разными кусками — «＋ Добавить ещё фрагмент», их можно набрать сколько угодно (𝄞 1–3, 𝄢 5–8, 𝄞 3–3…). Повторный проход по уже разобранному такту не пропадает: он делает такт крепче и ведёт к «закреплено».
- **Любой день.** Стрелки ‹ › у даты или тап по дню в календаре — отметить прошлое занятие задним числом. Уже отмеченный день можно **дополнить** («＋ дополнить»), если вспомнил ещё фрагмент. Один день — одна запись.
- **Старые дни без тактов.** Записи, сделанные до того, как появился выбор тактов, помечены в календаре пунктиром, а на самом дне — «📝 День отмечен, но такты не указаны» и кнопка «＋ указать такты»: выбираешь руку с диапазоном, и день дописывается в общий прогресс.
- **26 достижений** вместо уровней, и сразу видны не все: открытые показаны полностью, два ближайших дразнят условием, остальные — 🔒 «???». Есть секретные, которые находишь сам («Выходной у рояля», «Упрямец» — один такт семь раз, «Возвращение» после перерыва). Новое достижение — полноэкранный праздник с текстом по делу.
- **Неделя** — дни, сколько тактов пройдено, серия дней подряд.

## Общее для обоих треков

- **Мотивация и сатисфакция.** Пока день не отмечен, карточка сверху зовёт: серия под угрозой / ближайшее достижение рядом / тёплый пинок. После отметки — полноэкранное «Молодец! …Возвращайся завтра, будет 3 дня 🔥», а новое достижение показывается отдельным праздником.
- **Один день — одна запись**, но её можно дополнить. Прошлые дни отмечаются стрелками ‹ › у даты или тапом в календаре.
- Достижения закрыты: открытые видно полностью, два ближайших дразнят условием, остальные — 🔒 «???». Секретные не подсказываются вовсе.

## Синхронизация через GitHub Gist

1. ⚙️ Настройки → ссылка на создание токена: **classic**, галочка только **gist**, срок No expiration.
2. Вставить токен → «Подключить». Секретный гист `prokachka.json` создастся сам (или найдётся, если уже есть с другого устройства).
3. На втором устройстве — тот же токен, данные подтянутся.

Слияние по каждой записи (побеждает более свежая), удаления — «надгробиями» с очисткой через 60 дней. Токен хранится только на устройстве. Старые схемы данных (v1 «занятия», v2 «до какого такта», v3 «только пианино») мигрируют автоматически.
