# Прокачка

Трекер хобби, где прогресс привязан не к очкам и часам, а к самому делу: конкретной пьесе, книге, курсу. Три направления переключаются сегментом сверху:

- 🎹 **Пианино** — какие такты и какой рукой ты уже прошёл;
- 📖 **Чтение** — до какой страницы дочитал книгу;
- 🎨 **Пастель** — какие уроки курса пройдены.

Открыто на **https://buzulutskiy.github.io/prokachka/** · статический PWA без бэкенда: `index.html` + `app.js`. Данные — локально (localStorage), между устройствами синхронизируются через секретный **GitHub Gist**.

## Экраны

Шапка, переключатель хобби и нижняя навигация закреплены — прокручивается только содержимое вкладки.

**◉ Главная** — обложка, кольцо прогресса с процентом, название и подпись, две плашки (серия дней и счётчик наград), большая кнопка «Отметить» и короткая мотивашка. Всё помещается в экран без прокрутки на любом телефоне.

**Свайп по обложкам** (в «Пианино»): соседняя обложка выглядывает сбоку, свайп переключает композицию. Сейчас зашиты Бах — Прелюдия es-moll BWV 853 (40 тактов) и Микаэл Таривердиев — «Мальчики и море» (37 тактов). У каждой свой прогресс, календарь, серия и награды.

**Отметка — шторкой снизу.** Пианино: рука (правая / левая / обе) + диапазон «с такта по такт», можно добавить несколько фрагментов. Чтение: страница со степпером и кнопками +5/+10/+20/+50. Пастель: чекбоксы уроков. Плюс необязательная заметка и «Подтвердить». После — полноэкранный праздник: новое достижение или «Молодец, возвращайся завтра».

**▤ Прогресс** — карта тактов по рукам (полоса книги / список уроков), статистика недели, календарь и запись выбранного дня с навигацией по датам. Прошлые дни отмечаются задним числом, отмеченный день можно дополнить.

**✦ Награды** — сетка плиток: открытые цветные, два ближайших дразнят названием, остальные 🔒 «???». Тап открывает карточку награды снизу — иконка, название, статус, текст или условие, а для числовых целей — где ты сейчас.

**◈ Обзор** — радар «баланс развития» по трём осям (Пианино · Чтение · Пастель) с выводом «сильнее всего… проседает…» и разбивка по направлениям с процентами.

**🎲 Кубик в шапке** — решает, чем заняться сегодня: крутит варианты и останавливается на материале, объясняя выбор. Чаще выпадает то, что проседает и не отмечено сегодня.

## Достижения

Свои для каждого материала, контекстные:

- **Бах** — «Первый такт прелюдии», «Бас вступил», «Длинная фраза», «Отшлифовано», «Бах доволен»;
- **Таривердиев** — «Вышел к морю», «Первая волна», «Прибой в басу», «Волна за волной», «Отшлифовано прибоем», «Таривердиев доволен»;
- **Норштейн** — 🌫️ «Вошёл в туман», 🦔 «Ёжик вышел из тумана», 🫖 «Медвежонок ждёт с самоваром», 🍎 «Вечное яблоко», 🐺 «Волчок унёс книжку»; секретные: 🦉 «Филин следит», 🐴 «А лошадка-то в тумане», 🧣 «Как „Шинель“»;
- **Пастель** — «Собрал набор», «Час у мольберта», «Тест-драйв пройден», секретные про выходной и возвращение.

Один день — одна запись на материал; серии дней считаются отдельно по каждому.

## Синхронизация через GitHub Gist

1. ⚙️ Настройки → создать токен: **classic**, галочка только **gist**, срок No expiration.
2. Вставить токен → «Подключить». Секретный гист `prokachka.json` создастся сам (или найдётся с другого устройства).
3. На втором устройстве — тот же токен, данные подтянутся.

Слияние по каждой записи (побеждает более свежая), удаления — «надгробиями» с очисткой через 60 дней. Токен хранится только на устройстве. Все прошлые схемы данных (занятия → такты → две пьесы → три хобби) мигрируют автоматически.
