# Прокачка

Трекер разбора композиции на пианино. Не абстрактные XP и часы — прогресс привязан к конкретной вещи, которую разбираешь: **до какого такта дошла правая рука, до какого — левая**. Играешь с приложением и видишь, как становишься чуть лучше с каждым занятием.

Открыто на **https://buzulutskiy.github.io/prokachka/** · статический PWA без бэкенда: `index.html` + `app.js`. Данные — локально (localStorage), между устройствами синхронизируются через секретный **GitHub Gist**.

## Как устроено

Сейчас разбирается **Бах — Прелюдия es-moll, BWV 853** (40 тактов; название и число тактов правятся кнопкой «изменить» — фуга или следующая вещь тоже поместятся).

- **Карточка композиции** — общий % разбора и две полосы: 𝄞 правая рука (скрипичный ключ) и 𝄢 левая (басовый ключ), «до какого такта из 40». Рядом — следующая цель из лестницы достижений.
- **Отметить занятие** — степперы «до какого такта» по каждой руке (кнопки −/＋, тап по числу — ввести напрямую). Двигаешь только то, что сегодня разбирал; зелёный «+N» показывает прирост. Ничего не продвинул — тоже нормально: это повторение, оно засчитывается как занятие. День — либо отмечен, либо нет (одно занятие в день), после отметки кнопка гаснет до завтра.
- **Достижения** — вместо уровней: «Первые такты» → четверть/половина/три четверти каждой рукой → «Правая рука готова!» → 🏆 «Композиция разобрана!». Новое достижение — полноэкранный праздник.
- **Сатисфакция и мотивация** — после отметки: «Молодец! +2 такта правой. Возвращайся завтра — серия будет N 🔥». Пока день не отмечен, карточка сверху зовёт позаниматься (достижение рядом / серия под угрозой / просто тёплый пинок).
- **Календарь и неделя** — отмеченные дни, «+тактов за неделю», серия дней подряд. Прошлый день можно отметить задним числом.

## Синхронизация через GitHub Gist

1. ⚙️ Настройки → ссылка на создание токена: **classic**, галочка только **gist**, срок No expiration.
2. Вставить токен → «Подключить». Секретный гист `prokachka.json` создастся сам (или найдётся, если уже есть с другого устройства).
3. На втором устройстве — тот же токен, данные подтянутся.

Слияние по каждой записи (побеждает более свежая), удаления — «надгробиями» с очисткой через 60 дней. Токен хранится только на устройстве.

## Локальный запуск

```bash
python3 serve.py 8471
```

и открыть http://localhost:8471
