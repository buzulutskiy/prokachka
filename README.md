# Прокачка

Трекер разбора композиции на пианино. Прогресс привязан не к очкам и часам, а к самой вещи: **какие такты и какой рукой ты уже прошёл**. Играешь как хочешь — сегодня правой три такта, завтра левой те же самые, послезавтра ещё раз третий, потому что он тяжело идёт, — и видишь, как композиция заполняется.

Открыто на **https://buzulutskiy.github.io/prokachka/** · статический PWA без бэкенда: `index.html` + `app.js`. Данные — локально (localStorage), между устройствами синхронизируются через секретный **GitHub Gist**.

## Как устроено

Сейчас разбирается **Бах — Прелюдия es-moll, BWV 853** (40 тактов; название и число тактов правятся кнопкой «изменить»).

- **Карточка композиции** — общий процент разбора и две карты тактов: 𝄞 правая рука (скрипичный ключ) и 𝄢 левая (басовый). Каждый такт — клетка: тёмная (не трогал) → полупрозрачная (разобрал) → яркая (закрепил, 3+ прохода). Проценты по каждой руке отдельно.
- **Отметить занятие** — выбираешь руку (правая / левая / обе), диапазон «с такта — по такт» и жмёшь «Позанимался». Занимался разными кусками — «＋ Добавить ещё фрагмент», их можно набрать сколько угодно (𝄞 1–3, 𝄢 5–8, 𝄞 3–3…). Повторный проход по уже разобранному такту не пропадает: он делает такт крепче и ведёт к «закреплено».
- **Любой день.** Стрелки ‹ › у даты или тап по дню в календаре — отметить прошлое занятие задним числом. Уже отмеченный день можно **дополнить** («＋ дополнить»), если вспомнил ещё фрагмент. Один день — одна запись.
- **26 достижений** вместо уровней, и сразу видны не все: открытые показаны полностью, два ближайших дразнят условием, остальные — 🔒 «???». Есть секретные, которые находишь сам («Выходной у рояля», «Упрямец» — один такт семь раз, «Возвращение» после перерыва). Новое достижение — полноэкранный праздник с текстом по делу.
- **Мотивация и сатисфакция.** Пока день не отмечен, карточка сверху зовёт: серия под угрозой / ближайшее достижение рядом / тёплый пинок. После отметки — «Молодец! 𝄞 1–3, 𝄢 1–2. +5 тактов к разбору, всего 19%. Возвращайся завтра, будет 3 дня 🔥».
- **Неделя** — дни, сколько тактов пройдено, серия дней подряд.

## Синхронизация через GitHub Gist

1. ⚙️ Настройки → ссылка на создание токена: **classic**, галочка только **gist**, срок No expiration.
2. Вставить токен → «Подключить». Секретный гист `prokachka.json` создастся сам (или найдётся, если уже есть с другого устройства).
3. На втором устройстве — тот же токен, данные подтянутся.

Слияние по каждой записи (побеждает более свежая), удаления — «надгробиями» с очисткой через 60 дней. Токен хранится только на устройстве. Старые схемы данных (v1 «занятия», v2 «до какого такта») мигрируют автоматически.

## Локальный запуск

```bash
python3 serve.py 8471
```

и открыть http://localhost:8471
