# Кэйко (稽古)

Личный трекер занятий, который знает, **чем именно** ты занимаешься. Прогресс привязан не к абстрактным очкам, а к материалу: конкретной пьесе, книге, курсу.

Открыто на **https://buzulutskiy.github.io/prokachka/** · статический PWA без бэкенда (`index.html` + `app.js` + `sw.js`). Данные лежат локально, синхронизация — через секретный **GitHub Gist**.

Название — от японского 稽古 (кэйко): регулярная практика, где важен не результат, а сам повторяющийся заход.

---

## Профили

Два профиля — **Антон** и **Диана**. При первом запуске приложение спрашивает, кто занимается; сменить можно в настройках. У каждого свои материалы, записи, награды, мысли и полка. Гист при этом **один на двоих**: внутри файла данные разложены по разделам (`{ profiles: { anton: {…}, diana: {…} } }`), и профиль пишет только в свой раздел, не трогая чужой.

Локальные ключи тоже раздельные (`prokachka-data-v6`, `prokachka-data-v6-diana`), токен и номер гиста — общие.

## Материалы

Три вида занятий, у каждого своя единица прогресса:

- **🎹 Пианино** — такты и рука. Отмечаешь: правая / левая / обе, «с такта по такт», можно набрать несколько фрагментов за раз. Повторный проход не пропадает: три прохода делают такт «закреплённым».
- **📖 Чтение** — страница. Степпер плюс кнопки +5 / +10 / +20 / +50.
- **🎨 Пастель** — уроки курса, чекбоксами.

## Экраны

### ◉ Главная

Помещается в экран без прокрутки на любом телефоне.

- **Лента обложек** — бесконечная карусель, свайпом переключаешь материал. Фон приложения перекрашивается под обложку активного материала: оттенок берётся из самой картинки (сетка 24×24, самая заметная корзина цвета), а яркость и насыщенность задаются кодом — иначе тёмный корешок на тёмном фоне не читался бы.
- **Кольцо прогресса** с процентом.
- **Название и подпись** — глава/песнь/письмо и сколько страниц осталось; для пианино — проценты по рукам.
- **Прогноз**: «≈ 12 занятий · в таком темпе примерно к 3 сентября». Считается от медианы последних приростов и спокойного ритма «через день». Пропустил — назавтра дата сдвинется, это нормально.
- **Кнопка «Отметить»** — открывает шторку ввода.
- **🎲 Встряхивание телефона** — приложение само выбирает, чем заняться сегодня: лента разгоняется, крутит обложки и останавливается. Чаще выпадает то, что проседает и не отмечено сегодня.

### ▤ Прогресс

Общий по всем материалам, без переключателя.

- Режимы **Неделя** и **Месяц**: кольцо цели, метрики периода (серия, дни, такты, страницы, уроки), линейный график на весь период с видом вперёд.
- Месячная цель считается от недельной (4 в неделю × 4 недели).
- Общий **календарь** с цветными точками по видам занятий.
- Блок **«День»**: записи всех направлений за выбранную дату.

### ✎ Мысли

Читательский дневник в виде ленты, как в соцсети. Мысль не отмечает занятие и не влияет на серию.

- Сверху поле «Что подумалось?» и выбор материала — курсор ставится в поле сразу при переходе на вкладку.
- Ниже лента: свежие сверху, у каждой записи квадратная обложка материала, название, дата (год показывается, если он не текущий) и время.
- Запись можно **отредактировать** (✎) и удалить (✕, с подтверждением). Переносы строк сохраняются.
- **♥ Лайк** у каждой записи.
- В левом нижнем углу две кнопки: **сердечко со счётчиком** (включает показ только любимых) и **🎲 кубик** (вытягивает случайную мысль, повторное нажатие — следующую, та же дважды подряд не выпадает).
- Когда лента чем-то сужена, сверху появляется строка «♥ Только любимые» / «🎲 Одна наугад» с возвратом ко всей ленте.

## Мысль дня

Первый заход за день показывает одну из записанных мыслей: обложка материала, название, дата, текст. Внутри круга повторов нет — каждая мысль выпадает по разу, пока не пройдут все, потом круг начинается заново, и вчерашняя не может выпасть первой. Прямо там ставится сердечко.

Мыслей нет — экран не появляется вовсе. Не перебивает награды и карточки знаний. Выключается в настройках → Оформление. Настройка и история показов — свои у каждого профиля.

---

## Дисциплина без насилия

- **Цель на неделю** — сколько раз позаниматься чем угодно, не привязано к конкретным дням.
- **Серии** — две разные: серия по материалу (для его наград) и общая (для «Прогресса»). Награда «три дня подряд» у пианино не выдаётся за чтение.
- **Пауза** — задаёшь даты отпуска или болезни, эти дни не рвут серию. На главной висит «🌴 Пауза до …».
- **Архив** — пройденный материал уходит в архив, приложение спрашивает следующий.
- Один день — одна запись на материал, но её можно дополнить.

## Оформление

Семь цветовых тем: **Сумерки** (по умолчанию), **Розовый рассвет** (по умолчанию у Дианы), **Тушь и рис**, **Байкальский лёд**, **Тёплый вечер**, **Мох**, **Бумага**. И два «мира» со своим шрифтом и словарём интерфейса: **Орбита** (бортовой интерфейс, 1968) и **Терминал** (зелёный фосфор, ЭЛТ).

Визуально приложение сделано под iOS: стекло с `backdrop-filter`, пружинистые отклики на нажатие, плавные переходы, кроссфейд фона. Зум при фокусе на полях отключён, двойной тап не масштабирует, длинное нажатие не выделяет интерфейс — только тексты, которые захочется скопировать.

## Настройки

Отдельный экран из восьми разделов:

1. **Профиль** — кто занимается, смена профиля.
2. **Синхронизация** — гист, токен, ручная сверка, отключение, диагностика.
3. **Цель на неделю**.
4. **Оформление** — темы, миры, «Мысль дня».
5. **Материалы** — архив, возврат из архива.
6. **Пауза** — периоды, которые не рвут серию.
7. **Данные** — резервная копия и восстановление, импорт.
8. **О приложении** — версия, что такое кэйко, принудительное обновление, встряхивание.

## Сохранность данных

- Без подключённого гиста ввод заблокирован — чтобы записи не остались только на одном телефоне.
- При сбое синхронизации запись сначала сохраняется локально, сверху появляется баннер с кнопкой «Повторить».
- Слияние по `updatedAt`: два устройства не затирают друг друга, удаления помечаются флагом, а не стираются.
- **Резервная копия** — выгрузка всего в файл (через «Поделиться» на iOS) и восстановление из него со слиянием, а не заменой.
- Все прошлые схемы данных мигрируют автоматически (занятия → такты → две пьесы → три хобби → паузы и архив → профили → список книг).

## Офлайн и надёжность

- Service worker кэширует оболочку: приложение открывается без сети, cache-first, поэтому запуск мгновенный, а обновление подтягивается фоном.
- Сетевые запросы с таймаутом — офлайн не подвешивает интерфейс.
- Если что-то упало, показывается экран с текстом ошибки; один раз приложение пробует **починиться само** (снимает service worker и перезагружается начисто).
- Аварийный сброс: `?reset=1` в адресе — снимает воркер, чистит кэши, перезагружает.
- Удаление материалов, записей и отправка в архив — только с подтверждением.
- Перерисовка главной откладывается, пока лента обложек в движении, — свайп не сбивается фоновой синхронизацией.

## Обновления

Версия видна в настройках. При запуске приложение сверяет её с `version.json` мимо кэшей: вышла новая — показывает баннер «⬆️ Есть новая версия» с кнопкой «Обновить».

**При релизе поднимать втроём:** `APP_VERSION` в `app.js`, `version.json`, `CACHE` в `sw.js`.
