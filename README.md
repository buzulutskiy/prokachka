# Прокачка

Трекер привычек, который знает, чем именно ты занимаешься. Прогресс привязан не к абстрактным очкам, а к материалу: конкретной пьесе, книге, курсу.

Открыто на **https://buzulutskiy.github.io/prokachka/** · статический PWA без бэкенда (`index.html` + `app.js`). Данные локально, синхронизация — через секретный **GitHub Gist**.

## Три направления

- 🎹 **Пианино** — какие такты и какой рукой пройдены. Зашиты Бах, Прелюдия es-moll BWV 853 (40 тактов) и Микаэл Таривердиев, «Мальчики и море» (37 тактов, число тактов взято из партитуры в `~/Documents/Music/Projects/malchiki`). Между ними — свайп по обложкам, у каждой свой прогресс, календарь, серия и награды.
- 📖 **Чтение** — до какой страницы дочитал. Норштейн, «Снег на траве», том 1 (361 страница, старт со 183-й).
- 🎨 **Пастель** — какие уроки курса пройдены. Курс «Пастель · тест-драйв», 6 уроков (данные из проекта `pastel-course-viewer`).

## Экраны

**◉ Главная** — обложка, кольцо прогресса, название и подпись, кнопка «Отметить». Помещается в экран без прокрутки на любом телефоне.

**Отметка — шторкой снизу.** Пианино: рука (правая / левая / обе) + диапазон «с такта по такт», можно набрать несколько фрагментов. Чтение: страница со степпером и кнопками +5/+10/+20/+50. Пастель: чекбоксы уроков. Повторный проход по такту не пропадает — три прохода делают такт «закреплённым».

**▤ Прогресс** — общий по всем хобби, без переключателя. Режимы **Неделя** и **Месяц**: кольцо цели, метрики периода (серия, дни, такты, страницы, уроки) и линейный график на весь период с видом вперёд. Месячная цель считается от недельной (4 в неделю × 4 недели). Ниже — общий календарь с цветными точками по хобби и блок «День»: записи всех направлений за выбранную дату и кнопки «🎹 / 📖 / 🎨 отметить» для любого прошлого дня.

**✦ Награды** — двухуровневые: список материалов с процентом, тап — внутрь, кнопка «‹ Все материалы» назад. Открытый материал запоминается между вкладками и перезапусками. Награды контекстные: у Баха барочные, у Таривердиева морские, у Норштейна ёжик с самоваром и «Как „Шинель“», у пастели свои. Часть — секретные, без подсказок.

**🎲 Кубик в шапке** — решает, чем заняться сегодня: крутит варианты и объясняет выбор. Чаще выпадает то, что проседает и не отмечено сегодня.

## Дисциплина без насилия

- **Цель на неделю** — общая, не привязана ко дням: сколько раз в неделю позаниматься чем угодно. Настраивается в ⚙️.
- **Пауза** — задаёшь даты отпуска или болезни, эти дни не рвут серию. На главной висит «🌴 Пауза до …».
- **Архив** — пройденный материал уходит в архив с датой и процентом, приложение спрашивает следующий, а дни занятий остаются в статистике.
- Один день — одна запись на материал, но её можно дополнить.

## Сохранность данных

- Без подключённого гиста ввод заблокирован — чтобы записи не остались только на одном телефоне.
- При сбое синхронизации запись сначала сохраняется локально, сверху появляется баннер с кнопкой «Повторить».
- Все прошлые схемы данных мигрируют автоматически (занятия → такты → две пьесы → три хобби → паузы и архив).

## Обновления

Версия видна в ⚙️ внизу. Приложение при запуске сверяет её с `version.json` на сервере мимо кэшей: если вышла новая — показывает баннер «⬆️ Есть новая версия» с кнопкой «Обновить», которая снимает service worker, чистит кэши и перезагружает начисто.

При релизе поднимать втроём: `APP_VERSION` в `app.js`, `version.json`, `CACHE` в `sw.js`.
