# Прокачка

Трекер хобби с уровнями. Не просто «отметил день» — каждый час за занятием прокачивает навык, и ты по-настоящему переходишь с уровня на уровень, как в игре.

Статический PWA без бэкенда: `index.html` + `app.js`. Данные — локально (localStorage), между устройствами синхронизируются через секретный **GitHub Gist**.

## Как устроено

Времени в приложении нет совсем — сколько сидел за инструментом (15 минут, полчаса, час), не важно. **День либо отмечен, либо нет** — больше одного занятия в день не бывает.

- **«Позанимался!»** — одна большая кнопка: сел, поразбирал такты, нажал → **+10 XP**, кнопка гаснет до завтра. Рядом необязательная заметка («разбирал такты из …»). Отметка падает в выбранный день (по умолчанию — сегодня, можно тапнуть прошлый день в календаре и отметить задним числом).
- **Сатисфакция.** Сразу после отметки — полноэкранное «Молодец! Возвращайся завтра, серия будет N 🔥». Наверху живёт карточка-мотиватор: пока день не отмечен, она зовёт позаниматься (серия под угрозой / до уровня одно занятие / просто тёплый пинок), после — хвалит и ждёт завтра.
- **Календарь** — отмеченные дни подсвечиваются. Тап по дню — запись этого дня, там же можно удалить ошибочную.
- **Эта неделя** — сколько дней занимался, сколько XP набрал, серия «дней подряд».
- Пока в приложении одно хобби — «Пианино» с уровнями. Другие добавим, когда понадобятся.

## Уровни (пока только пианино)

Валюта прогресса — **опыт**: одно занятие = **+10 XP**. Лестница из 25 уровней: уровень 2 «Первый подход» — сразу после первого занятия, дальше шаг растёт плавно, чтобы прогресс чувствовался часто, а поздние уровни оставались честными. Названия и описания — про разбор композиций и репертуар.

Ключевые точки: 10 XP «Первый подход» (1 занятие) → 100 XP «В ритме» (10) → 280 XP «Крепкая база» (28) → 950 XP «Играющий» (95) → 1 500 XP «Любитель» (150) → 2 700 XP «Продвинутый» (270) → 4 800 XP «Легенда клавиш» (480) → 10 000 XP «Виртуоз» (1000 занятий). Полная лестница с описаниями открывается в карточке уровня.

- Прогресс-бар показывает движение **внутри текущего уровня** — каждое занятие видно.
- После каждой отметки — подбадривание и сколько занятий осталось до следующего уровня.
- При переходе на новый уровень — полноэкранное поздравление.

## Синхронизация через GitHub Gist

1. ⚙️ Настройки → ссылка на создание токена: **classic**, галочка только **gist**, срок No expiration.
2. Вставить токен → «Подключить». Секретный гист `prokachka.json` создастся сам (или найдётся, если уже есть с другого устройства).
3. На втором устройстве — тот же токен, данные подтянутся.

Слияние по каждой записи отдельно (побеждает более свежая), удаления — «надгробиями» с очисткой через 60 дней. Изменения уходят в гист через ~1,5 с после правки, а также при открытии приложения и возврате сети. Токен хранится только на устройстве.

## Локальный запуск

```bash
python3 serve.py 8471
```
